# HeyJugnu releases

Public macOS downloads and release notes for [HeyJugnu](https://heyjugnu.com).

Installers and update archives are attached under [Releases](https://github.com/Ikraam-Rasheed/heyjugnu-release/releases), not committed to this repository.

The app and website source code remain private. This repository contains only
this README and, once updates are published, the generated Sparkle update feed.

The first planned release is **0.46.6 beta** (build 466), requiring macOS 15.3
or later. No build has been published yet.
